Code Agent — 交互稿

本地的 Claude Code 工作台。v0.3 起交互稿直接用真实界面的截图：每页都是当前实现的样子，编号标注说明可交互的元素。 还没做、建议做的功能直接画进相关页面，用橙色编号和虚线框标出，页面标为「提议」。

阅读说明

1已实现的元素。鼠标移到编号或说明行上，截图里会框出对应元素；点编号跳到说明。
2提议新增的元素（截图里用虚线框画出）。
  • 截图来自真实运行的 Code Agent：脚本搭一套演示仓库，用一个按剧本回复的演示模型服务驱动会话，把每个页面带到要展示的状态再截图（1440 × 900）。所以审批、提问、计划、后台任务、审核循环这些状态都是真实流程跑出来的，演示模型叫 demo-pro / demo-lite。
  • 提议部分是用应用自己的样式类写的界面片段，注入真实页面后截图；每个提议页下面附了片段源码，实现时照着做就能还原。
  • 界面改了以后重新生成：node docs/prototype/tools/shoot.mjs（全部）或加页面编号只重拍几页，详见 tools/README.md。
  • 页面编号沿用 v0.2：同一编号还是同一个页面；v0.2 之后新增的页面从 P26 开始。需求编号（FR-…）对应 docs/requirements.zh-CN.md（v0.2，暂不修改）。

提议的功能

从需求 v0.2 里还没做、或只做了一半的功能里挑出来的，排除了用处不大、场景不符、和现有设计冲突或重叠、工作量大、有安全要求的（见下一节）。按建议的先后排列。

没有纳入的功能

需求 v0.2 里没做、这次也不建议做的，以及原因。用户已经明确砍掉的（自动权限模式、快速模式、费用显示、新建会话对话框等）不在这里重复，见 notes/cut-list.md。

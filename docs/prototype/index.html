Code Agent — 交互稿

基于 Claude Agent SDK（TypeScript）的本地 Web 工作台。下面每个页面的界面和布局全部用 SVG 绘制。 编号标注指向可交互的元素；每页下方的表格说明交互方式、界面行为以及所依赖的 SDK 接口。 需求编号（FR-…）对应 docs/requirements.zh-CN.md （英文版 docs/requirements.md）。

阅读说明

标注。点击标注跳到对应说明；鼠标悬停在说明上会高亮对应标注。
强调色 —— 主要操作、选中项、运行中状态。
警示 —— 需要用户处理（总是配合图标和文字）。
危险 —— 错误、破坏性操作、跳过权限检查。
正常 —— 已完成、已连接、已批准。
虚线框 —— 折叠或次要内容（思考过程、草稿）。

画布尺寸为 1440 × 900（1440 像素宽的桌面浏览器）。每页都可以单独打开或下载 SVG。 交互稿是静态的：交互之后的状态以单独页面或「变体」的形式给出。 界面文字为简体中文；代码、命令、工具名、SDK 字段和第三方内容保持原文，这本身也是多语言需求（FR-I18N）的一部分，详见 P25。

全局交互规则

方面规则
快捷键Ctrl K 命令 / 搜索 · Ctrl N 新建会话 · Enter 发送，Shift Enter 换行 · Esc 中断当前轮（输入框为空时）· Ctrl B 把运行中的工作转入后台 · Shift Tab 循环切换权限模式 · 1–4 在审批 / 提问面板中选择选项 · Ctrl . 开关检查器 · Alt ↑/↓ 切换运行中的会话。
输入法输入法组字期间按 Enter 只确认候选词，永远不会发送或提交。适用于所有「回车提交」的输入框。快捷键避开常见的输入法切换组合。
实时性每个运行中的会话通过一条 WebSocket 推送事件，每个事件带序号；重连后客户端请求最后序号之后的事件，服务端重放。界面上没有「发出即不管」的操作：每个命令都显示 进行中 → 完成 / 失败。
会话状态SDK 的 session_state_changed 驱动一个处处一致的指示：蓝色圆环 = 运行中，琥珀色圆点 + 「等待…」 = 需要你处理，灰色 = 空闲。浏览器标签页标题加前缀（● / !），网站图标加角标。
待处理优先会话需要你处理（审批、提问、计划、征询）时，请求停靠在输入框上方。若你在其他会话或标签页，顶栏铃铛计数，并（可选）发送浏览器通知。在任一处处理后，所有地方同步消失。
破坏性操作删除会话、回退文件、跳过权限检查和清空对话一律先确认，并说明哪些内容无法撤销。
版本适配当前运行的 Claude Code 版本（从 init 消息读取）不支持的功能会隐藏，或禁用并在提示中注明最低版本。
语言界面语言即时切换无需刷新（顶栏地球图标或 P25）。SDK 返回的代码映射为本地化文案并可展开原文；第三方内容和工具输出保持原文；Claude 生成的内容由「回复语言」决定。
空、加载、错误列表为空时显示一句说明和主要操作；加载时用骨架行；出错时显示本地化提示、SDK 原文和重试操作。会话级状态见 P24。
